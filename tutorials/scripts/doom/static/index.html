Decision latency is wall clock in the game loop, from the state being available to the action being available: prompt build plus one vLLM engine step (prefill of the fresh state tokens and one output token). Frame streaming is outside that time. Switching behavior changes only the control token: one checkpoint, one server, no adapter loading. The behaviors are imitation-learned from a scripted teacher, which sets their skill ceiling. The Jev post does not state its hardware or model, so this is not a like-for-like comparison.
